# 停靠岛（Pocket Isle）

[English](./README.md) | **简体中文**

> 一座停靠在 Windows 桌面边缘的手绘水彩小岛——将**无打扰文件临时中转**、**治愈系桌搭互动陪伴**、**独立番茄钟**与 **AI 水獭搭档**轻量地融于同一款 Electron 桌面应用。

---

## 一、项目概览

- **项目名称**：停靠岛（Pocket Isle）
- **运行平台**：Windows 10 / 11 桌面浮窗与轻工具（`Electron 45` · `React 18` · `TypeScript` · `electron-vite` · `Vitest`）
- **界面语言**：内置 **简体中文 (`zh-CN`) / 繁體中文 (`zh-TW`) / English (`en`) / 日本語 (`ja`) / 한국어 (`ko`) / Español (`es`)** 实时切换（可在「**⚙ 设置 → 通用与停靠设置**」或**系统托盘右键菜单 → 语言**中随时切换，即时生效于小岛、面板、托盘菜单、弹窗通知与 AI 提示词）
- **核心原则**：**绝不改动磁盘原文件** · **轻量不打扰** · **不配置 AI 也可 100% 离线使用**

---

## 二、为什么做停靠岛？

日常在 Windows 上写代码、做文档或与同事沟通时，经常会遇到这些小痛点：

1. **临时文件中转杂乱**：在微信、浏览器、桌面和文件夹之间反复传截图、资料或安装包时，文件很容易堆满桌面；而系统 `%TEMP%` 或聊天缓存目录下的文件过期后又会失效。
2. **传统工具栏太占视野**：常驻悬浮框占地方、有压迫感，而彻底隐藏的软件真要顺手传个文件时又要切窗口翻找。
3. **轻量的工作节奏陪伴**：想要一个安静的 25+5 番茄钟搭档，在文件堆里理清这轮要做的事，休息间隙还能摸摸小水獭、点亮路灯或放一只纸船放松心情。

**停靠岛（Pocket Isle）** 平时收拢为停靠在屏幕左/右边缘的一段 `320×240` 透明水彩小岛：待机仅露 `56px` 木栈桥与探头小水獭；靠近或拖入文件时自然滑出接货；随时左键将包裹拖给其他软件，或右键抓起扔进海里“扑通”一声收走。

## 三、核心功能亮点

### 1. 三段式贴边停靠与丝滑窗口交互
- **`docked`（贴边收拢态，露出 `56px`）**：安静停靠在屏幕左/右边缘，只露木栈桥尖端、系船桩、暂存数量角标与打盹小水獭。透明背景区域鼠标完全穿透（`setIgnoreMouseEvents(..., { forward: true })`），不遮挡底层任何窗口操作。
- **`peek`（迎宾半开态，露出 `148px`）**：鼠标或拖拽文件靠近时平滑滑出完整栈桥，展示最近 3 个文件对应的手绘包裹（文档呈**卷轴**、图片/压缩包呈**纸箱**、文本/代码呈**信封**，更多条目显示 `+N` 角标），悬停展示文件名牌与 AI 一句话简介。
- **`full`（完整小岛态，`320×240`）**：左键点击栈桥展开整座小岛；拖动靠近左右边缘 `64px` 内自动吸边，拉到屏幕中间则自由悬浮。窗口移动使用 `requestAnimationFrame` 对齐刷新率的相对位移以减少 DWM 重绘卡顿，并监听多屏 DPI/显示器变化自动约束坐标。

### 2. 零冲突文件暂存与双键手势
- **随手收纳**：
  - 支持将本地文件或文件夹直接拖到小岛或控制面板中暂存；
  - 在小岛或面板获得焦点时按 **`Ctrl+V`**，可直接把剪贴板中的**截图或文本**存为安全副本；
  - **安全存储策略**：普通本地路径仅存引用，不复制原文件；来自 `%TEMP%`、应用缓存目录或剪贴板的内容会自动安全复制到 `%APPDATA%\pocket-isle\dock-copies`（默认上限 `2 GB`，支持在设置中调整，具备配额预留并发保护与孤立副本清理）。
- **左/右键分流手势**：
  - **左键拖动包裹**：触发原生 `webContents.startDrag`，可直接拖入微信聊天窗、桌面、浏览器上传框或编辑器；
  - **右键拖入大海**（或点击名牌上的 **`🌊 扔海里`**）：小手动画抓起包裹送入水面、激起水花与涟漪后从码头移除（**绝不删除磁盘原文件**），并保留 20 秒限时撤销提示。
- **430×580 操作面板**（右键或双击栈桥开启）：
  - 支持右上角 **`📌 钉住面板`**（切换窗口不自动收起）与标题栏自由拖动；
  - 支持关键词搜索（`Ctrl+F`）、行内分组编辑、按 `mtimeMs` 缓存的缩略图、64 KB 纯文本/代码快速预览弹窗、一键复制图片/文本/路径及资源管理器定位。

### 3. 治愈系全岛互动与持久记忆
- **6 件手绘模块装饰 + 3 种氛围**：野花丛、木长椅、小路灯、圆冠树、小木屋、小风车独立开关；支持 **白天暖阳**、**星夜萤火** 与 **细雨听海** 三种氛围一键切换。
- **持久小岛记忆**：点击草地种下的小雏菊、手动开关的路灯和木屋暖窗均持久保存，下次启动依然陪伴在岛上。
- **趣味彩蛋互动**：点击或轻拍小水獭、长椅、野花（飞出蝴蝶）、圆冠树（落叶飘散）、野餐茶席（热茶与爱心）、岸边海星、海水（水圈涟漪），以及把折纸小船拖到水面上顺波漂流。

### 4. 本地多格式解析、AI 水獭搭档与独立番茄钟
- **轻量本地文本提取（运行在 `worker_threads` 后台线程，带字符/体积预算与随时中止）**：
  - 支持常见纯文本、代码、Markdown 与 CSV/TSV；
  - 零重依赖提取 `.docx` 正文、`.pptx` 幻灯片文本、`.xlsx` 工作表及前 40 行预览、以及 `.pdf` 内文（纯扫描件/图片 PDF 会诚实标注仅识别元数据）；
  - 可选启用压缩图片 **Vision 多模态识图**。
- **可随时取消的 AI 工作流**：
  - **AI 整理（`✦ AI 整理`）**：按选中项、当前筛选或全部条目生成分组标签、速览摘要与关注提醒；
  - **联合速览（`✦ 联合速览`）**：支持选中 2～6 个文件联合串读对比并附带可选对比侧重，生成带诚实读取回执的可复制 Markdown 卡片；
  - **专注步骤拆解**：根据输入目标与主动勾选的关联资料，生成 1 条专注小目标和 3 个可勾选微步骤；
  - **AI 推荐桌搭**：根据当前心情描述自动搭配装饰与昼夜/细雨氛围。
- **OpenAI 兼容接口与按源隔离密钥存储**：
  - 内置 **DeepSeek、通义千问（DashScope）、OpenAI、本地 Ollama（`localhost:11434`）、LM Studio（`127.0.0.1:1234`）** 快速模板；
  - 远程接口强制要求 `https://`（仅环回地址允许 `http://`）；
  - API Key 按规范化服务源（`protocol + host + port`）通过 Electron `safeStorage` 加密存放于本地，绝不把明文 Key 暴露到前端渲染层。
- **独立专注番茄钟**：支持自定义 `1–180` 分钟专注与 `1–60` 分钟休息、15 秒检查点持久化、锁屏/休眠自动暂停、系统桌面通知与轻柔三音铃声。

## 五、快速上手（Windows）

### 前置要求
- **系统**：Windows 10 / 11 (x64)
- **Node.js**：**v22.12.0+**（Electron 45 要求）

### 安装、运行与打包

```bash
# 1. 克隆仓库
git clone https://github.com/cowboyjun754/pocket-isle.git
cd pocket-isle

# 2. 安装依赖
npm install

# 3. 确保安装 Electron 45 运行时与类型定义（执行 typecheck / dev / package 前需就绪）
node node_modules/electron/install.js

# 4. 构建并在 Electron 中运行
npm run build
npx electron .

# 打包为免安装绿色版目录（输出 release/停靠岛/停靠岛.exe 与快捷方式）
npm run package

# 热重载开发模式
npm run dev
```

Windows 日常重启可运行仓库根目录下的 [`start-pocket-isle.bat`](start-pocket-isle.bat)（或 [`start-pocket-isle.vbs`](start-pocket-isle.vbs)），脚本会先优雅向已有实例发送 `--quit` 信号后再静默拉起最新版本（无残留黑框）。

### 自检与验证命令

```bash
# TypeScript 严格类型检查
npm run typecheck

# 单元测试套件（14 个测试文件，77 项测试）
npm test

# 生产构建（main + preload + renderer）
npm run build

# 完整 Windows 绿色包构建
npm run package
```

## 六、隐私与本地数据说明

- **零遥测追踪**：除用户主动点击 AI 分析或「测试连接」时向用户自行配置的模型端点发送请求外，应用无任何后台联网或数据统计。
- **数据完全保留本地**：设置、暂存引用、岛内副本（`dock-copies`）及 `safeStorage` 加密后的 API 密钥均只存于 `%APPDATA%\pocket-isle\data.json`，独立于项目仓库与安装包之外。
- **原文件绝对安全**：分组、AI 整理、清空列表或拖入大海等操作仅调整应用自身索引或管理副本，绝不会改写或删除磁盘原始文件。
